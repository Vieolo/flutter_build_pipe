# Migrating from < 0.4.0 to >= 0.4.0

Version 0.4.0 introduces three main breaking changes, one to the config and the rest to the format of the output:
- Replacing `print_stdout` with `output`
- Changing the structure of the output, both in terminal and the log files


## 1. Replacing `print_stdout` with `output` 
`print_stdout` was used to print all the output of the commands to the terminal.

It has been replaced with `output`. To replicate the behavior of the previous flag, you can set it to `verbose`.

```yaml
# before
print_stdout: true

# now
output: verbose
```


## 2. Structure of the output
The structure of the output to terminal and the structure of the log files are changed.

If you had relied on their on the structure of their output, you'd need to update your logic.
